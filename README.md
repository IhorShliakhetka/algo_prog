# Лабораторні роботи з дисципліни "Алгоритми та структури даних"
## Виконав: Ігор Ігорович Шляхетка (ІР-12)
## Лабораторна робота №8 (Варіант 1 Рівень 2)
В пошуках Святого Грааля Індіана Джонс зіткнувся з небезпечним випробуванням. Йому потрібно пройти крізь прямокутний коридор, який складається з крихких плит. На кожній плиті написана одна літера.  Правила проходженняМожна починати з будь-якої плити в найлівішому стовпці.  Виходом із коридору є верхня права та нижня права плити.  Індіана може переходити не лише на сусідню плиту, а й перестрибувати через кілька плит.  Щоб не провалитися крізь підлогу, він повинен дотримуватися таких правил:  Після кожного кроку Індіана повинен опинятися правіше, ніж був перед цим.  Завжди можна переходити на одну плиту праворуч.  Крім руху на одну плиту праворуч, можна перестрибувати, проте лише на ту саму літеру. Наприклад, з літери "a" можна перестрибнути на будь-яку іншу літеру "a" за умови, що ми цим ходом просунемося правіше.  Завдання
Для заданого коридору, підрахуйте, скільки всього існує способів пройти його успішно.  Вхідні дані (файл ijones.in) Вхідний файл складається з H+1 рядків:  Перший рядок містить два числа W і H, розділені пробілом: W — ширина коридору, H — висота коридору, від 1 до 2000.  Кожен з наступних H рядків містить слово довжиною W символів, яке складається з малих латинських літер.  Вихідні дані (файл ijones.out) Вихідний файл повинен містити одне ціле число — кількість різних шляхів для виходу з коридору.
